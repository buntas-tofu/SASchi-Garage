# LQ-001: A plausible package or API is not an executable capability

Status: candidate reference for migration practitioners; not an agency finding.
Evidence class: Publication-backed risk; SAS example and controls are engineering inference.
Runtime status: no model experiment or SAS execution performed for this card.
Family: dependency.

## Evidence and limits

Published research found fabricated package recommendations in evaluated code-generation settings. This establishes a failure class, not a current failure rate for our models or for SAS conversion.

## SAS migration scenario (illustrative)

A draft replaces a survey procedure with a convincing import and an estimator whose arguments are not in the installed library.

## Recommended control (inference)

Resolve the package to an approved distribution, pin its version, inspect the actual signature, and run a minimal call. An import alone does not prove that the estimator supports the required design.

## Proposed evaluation, not a measured result

Challenge with an intentionally unavailable API name and require rejection backed by the package reference. Keep the fixture independent of retrieved answer cards.

Keep new evaluation inputs and answers outside the retrieved teaching corpus.
Model name, revision, prompt, retrieved content, tool environment, and generation
settings must accompany any later empirical result.
